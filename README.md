# دليل منتزه الملك عبدالله – الملز، الرياض

دليل عربي مستقل وغير ربحي، يحافظ على صفحات الزيارة والأسئلة والخصوصية والتفضيلات والشروط. المراجع المؤرخة وحدودها منشورة في الصفحة؛ لا تُستنتج أسعار دخول أو مواعيد نافورة من ساعات إدراج خرائط خارجي.

## التطوير

Node.js 24.19.0 وpnpm 11.24.0 مثبتان في إعدادات المشروع. يُحفظ ملف القفل، ويسمح `pnpm-workspace.yaml` فقط ببرامج بناء esbuild وworkerd المطلوبة للأدوات الحالية.

```sh
corepack pnpm install --frozen-lockfile
pnpm check
pnpm build
node scripts/verify-20260922.mjs
node scripts/consent-test.mjs
node scripts/test-weather-panel.mjs
```

Astro يولد الصفحات الثابتة في `dist/` دون اتصال بمصدر الطقس أثناء البناء. Worker في `src/worker.ts` يخدم الملفات ومسار `/api/weather`؛ يُطلب توقع Open-Meteo عند استخدام الصفحة، ويُعرض وقت النموذج بتوقيت الرياض مع فشل واضح عند تعذر البيانات أو تقادمها. اقتراحات الملابس والجولة والأغراض وملاحظات الطقس ليست تنبيهات رسمية أو إعلاناً لتشغيل المرافق. المصدر مرخص CC BY 4.0 مع نسبة ظاهرة وبيان التعديل.

النطاق في `astro.config.mjs` وبيانات الكيان في `src/data/park.ts`، ومشروع Wrangler الحالي `kingabdullahpark`. فحص النشر وتفعيل النسخة ومراجعة العرض الفعلي مراحل منفصلة عن نجاح البناء المحلي.

## الصور والخصوصية

[MEDIA_SOURCES.md](MEDIA_SOURCES.md) يسجل المصدر الفردي لكل من الصورتين، وتظهر روابط المصدر والمؤلف والترخيص والتاريخ والتعديل بجوارهما. الصورة الاجتماعية الأصلية تبقى `public/og-cover.svg`.

تحتفظ صفحة cookies بالتحكم الموجود في Google Analytics، بالمفتاح `kap-consent-v1`. التحليل متوقف دون اختيار فعّال؛ الفئات غير المستخدمة لا تعرض مفاتيح وهمية. الاختبارات تشغل الملف المبني مع DOM وتخزين محاكيين؛ لا تثبت إرسال بيانات أو هندسة عرض متصفح.
